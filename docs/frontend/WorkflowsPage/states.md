# WorkflowsPage States

- **List View**: filtered SOP list is visible
- **Workspace View**: full-screen SOP workspace is open
- **New Draft**: blank SOP document and blank chat thread for new SOP creation
- **Validation Pass**: draft is ready to publish
- **Validation Fail**: draft needs correction and the failing section is highlighted
- **Publish Confirm**: explicit publish confirmation is visible before go-live
