# TopBar Change Log

**Version 1.0.0**
- Date: 2026-02-24
- Change: Initial module creation.
- Reason: Split layout concerns away from `App.jsx` and old components to allow for a dedicated left-aligned sidebar and top-aligned branding bar.
- Impact: Provides a scalable header system for injecting notifications or settings in the future without modifying actual page routes.

**Version 1.1.0**
- Date: 2026-02-26
- Change: Introduced the Settings Dropdown. Added User Profile display and the Developer Mode toggle.
- Reason: Accommodate the new context-based global security restrictions (Phase 9) and personalize the UI.
