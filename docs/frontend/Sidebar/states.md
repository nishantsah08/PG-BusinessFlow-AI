# Sidebar States

- **Expanded View (Desktop - md+)**: Shows 64-width panel with label text ("Systems") and full link labels ("Master AI", "Property & Booking", "CRM", and "Agent Dashboard" if Developer Mode is enabled).
- **Collapsed View (Mobile - <md)**: Shrinks to a 16-width vertical strip rendering just the icons without text.
- **Active Navigation (`isActive = true`)**: Applies soft indigo backgrounds to visually anchor the user on their current page.
