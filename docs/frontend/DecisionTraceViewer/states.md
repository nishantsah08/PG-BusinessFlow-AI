# DecisionTraceViewer State Behaviors

Conforms strictly to the 5 mandatory UI states via `StateWrapper`.

## 1. empty
- **Trigger:** Initial mount with `traceId === null`, or when `apiClient` returns an explicit 404/not-found error for the requested trace.
- **Behavior:** Renders the "Select or make a request to view decision trace." message.

## 2. loading
- **Trigger:** The `traceId` prop changes to a non-null string, initiating a fetch.
- **Behavior:** Renders the standard `StateWrapper` spinner.

## 3. success
- **Trigger:** `apiClient` returns `success: true` and the trace JSON payload.
- **Behavior:** `StateWrapper` renders the structured payload (execution plan & sub_tasks).

## 4. error
- **Trigger:** `apiClient` returns `success: false` with a non-404 error, or a parsing crash occurs.
- **Behavior:** `StateWrapper` visually displays the `errorMsg`.

## 5. retry
- **Trigger:** The 'Retry' button generated by `StateWrapper`.
- **Behavior:** Invokes `fetchTrace(traceId)`, triggering the UI `loading` state to re-attempt fetching the current trace.
